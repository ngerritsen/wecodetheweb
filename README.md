# We Code The Web

A blog about front-end/web development - brainfood for front-end developers.

Built with [Astro](https://astro.build/) and deployed to Netlify.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Features

- Static site generation with Astro
- MDX content collections for blog posts
- Optimized images with WebP conversion
- RSS feed
- Disqus comments
- SEO optimized
